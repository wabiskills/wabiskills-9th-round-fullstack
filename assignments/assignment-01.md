
# Assignment 06: Introduction to Express.js

WabiSkills – 9th Round Fullstack Web Development

 Objective

The objective of this assignment is to help students understand how to create a basic web server using Node.js and Express.js.

 Tasks

 Task 1: Project Setup
1. Create a new Node.js project.
2. Initialize it using `npm init -y`.
3. Install Express.js using `npm install express`.
4. Create a file named `server.js`.

 Task 2: Create an Express Server

1. Import Express.
2. Create an Express application.
3. Start the server on port 3000.
4. Display a message in the terminal when the server starts.

 Task 3: GET Request

Create a GET route at `/` that responds with:

`Welcome to WabiSkills 9th Round!`

 Task 4: POST Request

Create a POST route at `/register` that receives student information:

- Full name
- Email
- Course

Use `req.body` to access the submitted information and send a successful response.

Task 5: Testing

Test your GET and POST requests and provide screenshots of the results.

 Submission Requirements

Submit the following:

- `server.js`
- `package.json`
- A README.md explaining your implementation.
- Screenshots of your GET and POST request tests.

## Important

- Write your own code.
- Do not copy another student's solution.
- Be prepared to explain your implementation.
