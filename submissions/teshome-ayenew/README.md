### Project Description
This project demonstrates the creation of a basic web server using Node.js and Express.js.

### Technologies Used
- Node.js
- Express.js
- JavaScript
- Visual Studio Code

### Implemented Features

1. Created an Express.js server.
2. Configured the server to run on port 5000.
3. Created a GET route (`/`) that displays a welcome message.
4. Created a POST route (`/register`) to receive student information.
5. Used Express JSON middleware to process JSON data.

### API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | / | Welcome message |
| POST | /register | Student registration |

### How to Run the Project

1. Install Node.js.
2. Open the project folder in VS Code.
3. Install dependencies:

   npm install

4. Start the server:

   node server.js

5. Open your browser:

   http://localhost:5000
